# 台灣水庫即時資訊網站

## 第 1 步：資料（完成，2026-10-10 第一份快照）
- `scripts/fetch_reservoirs.py`：抓水利署開放資料 41568（每日營運）與 45501（每小時水情），合併後輸出：
  - `data/latest.json`：每座水庫最新狀況（網站讀這個）
  - `data/snapshots/YYYY-MM-DD.json`：每日快照，累積歷史
  - `data/history.csv`：一列＝一座水庫一天，畫趨勢用
- 資料實際放在 `opendata.wra.gov.tw`（data.gov.tw 只是目錄頁）。
- 蓄水率 = 有效蓄水量 ÷ 有效容量（每小時資料本身沒有百分比欄位）。

## 第 2 步：網站頁面（預覽版完成 2026-10-10）
- `index.html`：單一檔案，讀 `data/latest.json` 和 `data/history.csv`。放 GitHub Pages 時 repo 根目錄就是這個資料夾。
- 本島總蓄水率、地區分頁、兩種排序、地圖（圓點大小＝容量、顏色深淺＝蓄水率、低於 30% 紫色外圈）、每座水庫的 30 天小趨勢圖（資料累積兩天後出現）。
- 官方資料沒有座標：地圖用手寫的簡化海岸線和約略位置，只畫本島。
- 預覽網址：https://claude.ai/artifact/RnhtCgDUg7K1d5jxGwKGmK

## 第 3 步：差異化功能（進行中）
- 可用天數：Shane 決定以政府公告為準、不自己估算（2026-10-10 已拿掉）。水利署開放資料沒有公告天數。
- 去年同期：`last_year_percent` 從 history.csv 找一年前 ±3 天。公開 API 沒有歷史資料，所以要等自己的紀錄滿一年（2027-10 起）才會出現。
- 水情燈號（2026-10-10）：官網 EarlyWarning 頁只有一張全台燈號圖＋發布日期，沒有結構化資料。腳本抓圖片網址和日期存 `data/alert.json`，並把圖下載成 `data/alert-map.png`（需要 www-ws.wra.gov.tw）。
- 收藏：Shane 決定不做（2026-10-10）。

## 第一面改版（2026-10-10，Shane 意見）
- 拿掉「本島總蓄水率」（各區落差大，平均沒意義）。第一面改成「各區水情」：北／中／南／東／離島各一列，官方燈號＋該區前 3 大水庫蓄水率。
- 燈號地圖：用官方燈號圖（480×568）當底圖，依各縣市燈號填色，再畫水庫圓點。縣市燈號由腳本在每個縣市內的一點取樣判讀（`COUNTY_SEEDS`，網頁 `SEEDS` 同一份）。官方換圖尺寸時會自動改顯示原圖。
- 經緯度→官方圖像素：用 4 個海角對齊的仿射轉換，誤差約 5 像素。

## 注意
水利署要求：蓄水率不要用綠、黃、橙、紅色表示，以免和官方「水情燈號」混淆。

## 目前資料狀況（2026-10-10）
- 68 座水庫／攔河堰，55 座算得出蓄水率。
- 缺蓄水率的多半是只填每日資料、沒有每小時資料的（如烏山頭、白河），或是攔河堰本來就沒容量。
- `suspect: true`：蓄水率超過 105%，多半是來源填錯（后沃水庫 5878%）；阿公店 129% 可能是汛期降低容量運轉。
- API 只給最新資料，歷史要靠每天存快照累積；30 天趨勢要回補的話需另找來源。
- Python 3.13 會因政府憑證缺欄位而拒絕連線，程式裡已處理。
